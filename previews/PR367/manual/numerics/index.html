Numerical solution

A closed MeanfieldEquations is a system of ordinary differential equations for complex averages. There are two ways to integrate it. The ModelingToolkit route builds a System, which handles time-dependent drives, registered functions and stochastic noise. The direct backend builds an ODEProblem without ModelingToolkit, which is faster to set up and cheap to re-parametrise, but accepts only polynomial deterministic drifts.

We integrate the phase-invariant laser of Closing the hierarchy.

using QuantumCumulantsimport QuantumCumulants.SecondQuantizedAlgebra as SQAh = FockSpace(:cavity) ⊗ NLevelSpace(:atom, (:g, :e))@qnumbers a::Destroy(h)σ(i, j) = Transition(h, :σ, i, j)@variables Δ::Real g::Real γ::Real κ::Real ν::RealH = Δ * a' * a + g * (a' * σ(:g, :e) + a * σ(:e, :g))J = [a, σ(:g, :e), σ(:e, :g)]phase(op) = SQA.is_create(op) - SQA.is_destroy(op) +    (SQA.is_transition(op) ? sign(op.l1 - op.l2) : 0)phase_invariant(avg) = iszero(sum(phase, SQA.get_operators(SQA.undo_average(avg)); init = 0))eqs = complete(meanfield([a' * a], H, J; rates = [κ, γ, ν], order = 2); filter_func = phase_invariant)ps = Dict(Δ => 0.0, g => 1.5, γ => 0.25, κ => 1.0, ν => 4.0)

ModelingToolkit

Each moment becomes one unknown $u(t)$ of the System, and every symbol on a right-hand side that is not a moment becomes a parameter. moment_variable_map shows the assignment.

using ModelingToolkitBase, OrdinaryDiffEqTsit5sys = mtkcompile(System(eqs; name = :laser))moment_variable_map(eqs)
OrderedCollections.OrderedDict{SymbolicUtils.BasicSymbolicImpl.var"typeof(BasicSymbolicImpl)"{SymReal}, SymbolicUtils.BasicSymbolicImpl.var"typeof(BasicSymbolicImpl)"{SymReal}} with 3 entries:
  ⟨a' * a⟩   => ⟨a' * a⟩(t)
  ⟨a' * σ₁₂⟩ => ⟨a' * σ₁₂⟩(t)
  ⟨σ₂₂⟩      => ⟨σ₂₂⟩(t)
ModelingToolkitBase.System — Method
ModelingToolkitBase.System(eqs::MeanfieldEquations; name, kwargs...)
ModelingToolkitBase.System(eqs::NoiseMeanfieldEquations; name, kwargs...)

Build an MTK System from the equation set: one u(t) variable per state, the drift resolved to those variables. A NoiseMeanfieldEquations becomes an SDE with one independent Brownian column per monitored channel, each carrying that channel's noise drift (sign +1 Forward, -1 Backward). RHS leaves not matching a state become parameters.

Any extra kwargs are forwarded to the underlying ModelingToolkitBase.System constructor. In particular bindings = [p => expr, ...] marks a parameter as derived from others, so it is computed from the supplied values rather than set directly (see the effective model in the unique-squeezing example).

Initial values

ModelingToolkit takes initial values as a map from unknowns to numbers. initial_values builds it from a vector aligned with states, or from a numerical quantum state through SecondQuantizedAlgebra's numeric conversion. Here the cavity starts in a coherent state and the atom in its ground state.

using QuantumOpticsBaseψ0 = coherentstate(FockBasis(10), 0.5) ⊗ nlevelstate(NLevelBasis(2), 1)u0 = initial_values(eqs, ψ0)prob = ODEProblem(sys, merge(u0, ps), (0.0, 10.0))sol = solve(prob, Tsit5())

Reading the solution

get_solution resolves an operator or an average to the matching state, including states stored only through their complex conjugate, and returns a callable trajectory.

n = get_solution(sol, a' * a, eqs)n(10.0)
1.4831251668565208 + 0.0im
QuantumCumulants.get_solution — Function
get_solution(sol, avg_or_op, eqs)

Query an ODE/SDE solution for the trajectory of an average (or a QField, averaged internally). Resolves the user's operator to a tracked state through the single structural matcher match_moment, which folds Hermitian conjugation (the side bit recovers a stored conjugate) and the system's index/symmetry treatment, so a query posed in any equivalent symbolic form hits the same state.

Direct backend

The direct backend lowers the equations once to a polynomial representation and evaluates them with a compact kernel. It is selected explicitly with backend = KernelBackend() and takes the same initial values, as a map, a vector aligned with states, or the quantum state itself.

prob_k = ODEProblem(eqs, u0, (0.0, 10.0), ps; backend = KernelBackend())sol_k = solve(prob_k, Tsit5())get_solution(sol_k, a' * a, eqs)(10.0)
1.4831271034116937 + 0.0im

Parameters can be changed in place without lowering the equations again, which suits parameter sweeps. Updates may be partial. For independent sweeps on several threads, give each task its own copy of the problem.

update_parameters!(prob_k, Dict(g => 2.0))get_solution(solve(prob_k, Tsit5()), a' * a, eqs)(10.0)
1.7930136019184548 + 0.0im

The backend accepts polynomial drifts with state-independent coefficients. Time-dependent coefficients and other functions of the states have to go through ModelingToolkit. For implicit solvers the backend also provides the exact sparse Jacobian with jac = true. This requires an unfolded closure (get_adjoints = true in complete), since a single complex Jacobian is not the full derivative of $f(u, u^*)$.
