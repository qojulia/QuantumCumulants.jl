Working with equations

A MeanfieldEquations is more than a list of equations. It holds the cumulant hierarchy as a graph of moments, and every function on this page reads or rewrites that graph. Changes therefore survive later steps: a modified right-hand side is still modified after complete, scale or evaluate.

  • Inspecting the moments
  • Simplification
  • Substitution
  • Adding terms by hand

The examples continue with the phase-invariant laser of Closing the hierarchy.

using QuantumCumulants
import QuantumCumulants.SecondQuantizedAlgebra as SQA

h = FockSpace(:cavity) ⊗ NLevelSpace(:atom, (:g, :e))
@qnumbers a::Destroy(h)
σ(i, j) = Transition(h, :σ, i, j)
@variables Δ::Real g::Real γ::Real κ::Real ν::Real

H = Δ * a' * a + g * (a' * σ(:g, :e) + a * σ(:e, :g))
J = [a, σ(:g, :e), σ(:e, :g)]

phase(op) = SQA.is_create(op) - SQA.is_destroy(op) +
    (SQA.is_transition(op) ? sign(op.l1 - op.l2) : 0)
phase_invariant(avg) = iszero(sum(phase, SQA.get_operators(SQA.undo_average(avg)); init = 0))

eqs = complete(meanfield([a' * a], H, J; rates = [κ, γ, ν], order = 2); filter_func = phase_invariant)

Inspecting the moments

Each equation belongs to one tracked moment. The operator products, their averages, and the pairing between the two are available separately.

operators(eqs)

\[ \left[ \begin{array}{c} a^{\dagger}a \\\\ a^{\dagger}{\sigma}^{{12}} \\\\ {\sigma}^{{22}} \\\\ \end{array} \right] \]

moments(eqs)
OrderedCollections.OrderedDict{SecondQuantizedAlgebra.QAdd, SymbolicUtils.BasicSymbolicImpl.var"typeof(BasicSymbolicImpl)"{SymReal}} with 3 entries:
  a' * a   => ⟨a' * a⟩
  a' * σ₁₂ => ⟨a' * σ₁₂⟩
  σ₂₂      => ⟨σ₂₂⟩

Simplification

Derivation leaves right-hand sides unsimplified, since simplification is expensive and rarely needed before numerics. Call it when you want to read the equations.

simplify(eqs)

\[ \begin{aligned} \partial_{t} \langle a^{\dagger}a \rangle &= - \langle a^{\dagger}a \rangle \kappa + \langle a{\sigma}^{{21}} \rangle g i - \langle a^{\dagger}{\sigma}^{{12}} \rangle g i \\\\[-0.0em] \partial_{t} \langle a^{\dagger}{\sigma}^{{12}} \rangle &= \langle {\sigma}^{{22}} \rangle g i - \langle a^{\dagger}a \rangle g i + \langle a^{\dagger}{\sigma}^{{12}} \rangle \left( - \frac{1}{2} \left( \gamma + \kappa + \nu \right) + i \Delta \right) + 2 \langle {\sigma}^{{22}} \rangle \langle a^{\dagger}a \rangle g i \\\\[-0.0em] \partial_{t} \langle {\sigma}^{{22}} \rangle &= \nu + \langle {\sigma}^{{22}} \rangle \left( - \gamma - \nu \right) + \langle a^{\dagger}{\sigma}^{{12}} \rangle g i - \langle a{\sigma}^{{21}} \rangle g i \end{aligned} \]

QuantumCumulants.simplify! — Function
simplify!(eqs::AbstractMeanfieldEquations; kwargs...)
simplify(eqs::AbstractMeanfieldEquations; kwargs...)

Run SymbolicUtils.simplify on every RHS in eqs (and on the noise drift RHSs of a NoiseMeanfieldEquations). simplify! mutates; simplify returns a fresh struct. The derivation pipeline leaves expressions raw so the cost of SymbolicUtils.simplify is paid only when explicitly requested.

Substitution

Substituting a parameter or a vanishing average rewrites every right-hand side at once, e.g. to go on resonance.

substitute(eqs, Dict(Δ => 0))

\[ \begin{aligned} \partial_{t} \langle a^{\dagger}a \rangle &= - \langle a^{\dagger}a \rangle \kappa + \langle a{\sigma}^{{21}} \rangle g i - \langle a^{\dagger}{\sigma}^{{12}} \rangle g i \\\\[-0.0em] \partial_{t} \langle a^{\dagger}{\sigma}^{{12}} \rangle &= \langle a^{\dagger}{\sigma}^{{12}} \rangle \left( - \frac{1}{2} \gamma - \frac{1}{2} \kappa - \frac{1}{2} \nu \right) + \langle {\sigma}^{{22}} \rangle g i - \langle a^{\dagger}a \rangle g i + 2 \langle {\sigma}^{{22}} \rangle \langle a^{\dagger}a \rangle g i \\\\[-0.0em] \partial_{t} \langle {\sigma}^{{22}} \rangle &= \nu + \langle {\sigma}^{{22}} \rangle \left( - \gamma - \nu \right) + \langle a^{\dagger}{\sigma}^{{12}} \rangle g i - \langle a{\sigma}^{{21}} \rangle g i \end{aligned} \]

QuantumCumulants.substitute! — Function
substitute(eqs::AbstractMeanfieldEquations, dict::AbstractDict)
substitute!(eqs::AbstractMeanfieldEquations, dict::AbstractDict)

Substitute dict into every RHS of eqs (and into the noise drift RHSs of a NoiseMeanfieldEquations). Keys of dict are symbolic expressions to replace: parameters, or averages known to vanish (e.g. by symmetry), so that zeroing them closes the hierarchy onto the remaining moments. substitute! mutates eqs; substitute returns a fresh struct. The substitution also applies to the equations a later complete derives.

Only the drifts are rewritten; the moment set (the LHS states and operators) is unchanged. To also drop the substituted moments as unknowns, complete onto the reduced subset (e.g. with a filter_func) or rebuild meanfield on it.

# close a phase-invariant model onto ⟨σ⁺ᵢσ⁻ⱼ⟩ by asserting the single-operator averages vanish
eqs = meanfield(ops, H, J; rates, order = 2)
eqs = substitute(eqs, Dict(average(σ(2, 1, i)) => 0 for i in 1:N))

Adding terms by hand

Some terms do not come from a Hamiltonian or a Lindblad dissipator, such as a phenomenological drive or a coupling to an external reservoir. modify_equations rewrites each right-hand side with a function of the left-hand operator. Here we add a coherent drive of the cavity to the laser.

@variables η::Real
Hd = η * (a + a')
add_drive(lhs, rhs) = rhs + cumulant_expansion(average(1im * commutator(Hd, lhs)), 2)
eqs_d = modify_equations(eqs, add_drive)

The drive breaks the phase invariance, so the modified system is no longer closed. find_missing reports the averages that the new terms introduced.

find_missing(eqs_d)
2-element Vector{SymbolicUtils.BasicSymbolicImpl.var"typeof(BasicSymbolicImpl)"{T} where T}:
 ⟨a⟩
 ⟨σ₁₂⟩

The rewrite is recorded on the system, and complete applies it to every equation it derives afterwards. The result is the same as putting the drive into the Hamiltonian from the start.

eqs_dc = complete(eqs_d)
closure_report(eqs_dc)
(n_states = 8, by_order = OrderedCollections.OrderedDict(1 => 3, 2 => 5), missing = SymbolicUtils.BasicSymbolicImpl.var"typeof(BasicSymbolicImpl)"{T} where T[], closed = true)

substitute! is recorded in the same way, so a parameter set to zero stays zero in later equations too.

QuantumCumulants.modify_equations — Function
modify_equations(eqs::AbstractMeanfieldEquations, f::Function)

Return a copy of eqs whose RHS for each equation has been rewritten by f. The function is called as f(lhs_op, rhs), receiving the operator form of the LHS (undo_average(eq.lhs)) and the symbolic RHS, and returning a new RHS. The rewrite is recorded on the system, so the equations a later complete derives receive it as well.

f(lhs, rhs) = rhs + cumulant_expansion(average(commutator(1im * Hadd, lhs)), 2)
eqs_mod = modify_equations(eqs, f)

See also modify_equations!.

source
