Closing the hierarchy

Truncation bounds the order of the averages, but it does not bound their number. A truncated equation still refers to averages of lower or equal order that have no equation of their own, and the system is closed only once every average on a right-hand side is also a state. Closing is a reachability sweep: derive an equation for each missing average, collect the averages its right-hand side introduces, and repeat until nothing new appears.

  • Finding missing averages
  • Completing a system
  • Filtering averages

We use the single-atom laser of Getting started throughout.

using QuantumCumulantsh = FockSpace(:cavity) ⊗ NLevelSpace(:atom, (:g, :e))@qnumbers a::Destroy(h)σ(i, j) = Transition(h, :σ, i, j)@variables Δ::Real g::Real γ::Real κ::Real ν::RealH = Δ * a' * a + g * (a' * σ(:g, :e) + a * σ(:e, :g))J = [a, σ(:g, :e), σ(:e, :g)]eqs = meanfield([a' * a], H, J; rates = [κ, γ, ν], order = 2)

Finding missing averages

find_missing lists the averages that still lack an equation, and closure_report summarises the state of the whole set.

closure_report(eqs)

QuantumCumulants.find_missing — Function
find_missing(eqs::AbstractMeanfieldEquations; filter_func=nothing)

Return the averages that appear on a right-hand side of eqs but are not yet among its tracked states: the equations still needed to close the system. A moment and its conjugate count as one: if either is already a state, neither is reported. filter_func mirrors complete!.

The report is representation-invariant: conjugate pairs are always folded onto one key, so the answer is the same whether eqs was closed with get_adjoints true or false.

See also: complete, complete!.

QuantumCumulants.closure_report — Function
closure_report(eqs::AbstractMeanfieldEquations; filter_func=nothing)

Summarise the closure status of eqs:

  • n_states: number of tracked moments.
  • by_order: tracked-moment count per cumulant order.
  • missing: moments still needed to close the system (find_missing).
  • closed: whether nothing is missing.

filter_func mirrors find_missing / complete!.

Completing a system

complete runs the sweep to its end. A moment and its complex conjugate count as one state, since the equation of one is the conjugate of the other.

eqs_c = complete(eqs)closure_report(eqs_c)
(n_states = 8, by_order = OrderedCollections.OrderedDict(1 => 3, 2 => 5), missing = SymbolicUtils.BasicSymbolicImpl.var"typeof(BasicSymbolicImpl)"{T} where T[], closed = true)
ModelingToolkitBase.complete — Function
complete(eqs::AbstractMeanfieldEquations; order=nothing, kw...)

Non-mutating complete!: derive equations of motion for every average that appears on a right-hand side but is not yet a state, returning a new closed system.

Keyword arguments

  • order=nothing: if given, the copy is first cumulant-expanded to this order (deterministic systems only) before closing.
  • kw...: forwarded to complete! (max_iter, filter_func, get_adjoints).

See also: complete!, find_missing, meanfield.

source
QuantumCumulants.complete! — Function
complete!(eqs::AbstractMeanfieldEquations; max_iter=100_000, filter_func=nothing,
          get_adjoints=false)

Close eqs in place by repeatedly deriving equations of motion for every average that appears on a right-hand side but is not yet a state, until the set is self-contained. Closure reads and rewrites eqs.graph, so user RHS modifications and filter substitutions already recorded there survive. Right-hand sides are left unsimplified.

Keyword arguments

  • max_iter=100_000: runaway backstop; an error is raised if closure has not converged within this many iterations.
  • filter_func=nothing: a predicate filter_func(avg); rejected averages are dropped (substituted by 0), e.g. to discard phase-invariant terms.
  • get_adjoints=false: by default only one representative per conjugate pair is tracked, with the partner recovered by conj at code generation (the minimal state set). Pass true to integrate each conjugate as its own (redundant) state.

See also: complete, find_missing, meanfield.

Filtering averages

A symmetry often guarantees that some averages vanish at all times. The laser is invariant under a global phase rotation $a \to a e^{i\phi}$, $\sigma^{ge} \to \sigma^{ge} e^{i\phi}$, so every average whose operators carry a net phase stays zero from a phase-invariant initial state. Passing a predicate as filter_func drops these averages during the sweep and keeps the system minimal.

import QuantumCumulants.SecondQuantizedAlgebra as SQAphase(op) = SQA.is_create(op) - SQA.is_destroy(op) +    (SQA.is_transition(op) ? sign(op.l1 - op.l2) : 0)phase_invariant(avg) = iszero(sum(phase, SQA.get_operators(SQA.undo_average(avg)); init = 0))eqs_f = complete(eqs; filter_func = phase_invariant)

\[ \begin{aligned} \partial_{t} \langle a^{\dagger}a \rangle &= - \langle a^{\dagger}a \rangle \kappa + \langle a{\sigma}^{{21}} \rangle g i - \langle a^{\dagger}{\sigma}^{{12}} \rangle g i \\\\[-0.0em] \partial_{t} \langle a^{\dagger}{\sigma}^{{12}} \rangle &= \langle {\sigma}^{{22}} \rangle g i - \langle a^{\dagger}a \rangle g i + \langle a^{\dagger}{\sigma}^{{12}} \rangle \left( - \frac{1}{2} \gamma - \frac{1}{2} \kappa - \frac{1}{2} \nu + i \Delta \right) + 2 \langle {\sigma}^{{22}} \rangle \langle a^{\dagger}a \rangle g i \\\\[-0.0em] \partial_{t} \langle {\sigma}^{{22}} \rangle &= \nu + \langle {\sigma}^{{22}} \rangle \left( - \gamma - \nu \right) + \langle a^{\dagger}{\sigma}^{{12}} \rangle g i - \langle a{\sigma}^{{21}} \rangle g i \end{aligned} \]

The filter must encode a property of the dynamics, not a preference. Dropping an average that does evolve silently changes the physics.
