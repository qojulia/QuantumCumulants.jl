QuantumCumulants.jl

Generalized mean-field equations for open quantum systems

Derive Heisenberg equations for expectation values symbolically, truncate them with the cumulant expansion at any order, and solve the closed system numerically.

ModelingToolkit bridge

Turn the equations into a ModelingToolkit System and solve them with the SciML differential equation solvers.

QuantumCumulants derives equations of motion for operator averages from the fundamental commutation relations and closes them with the generalized cumulant expansion (Plankensteiner et al., 2022). The operator algebra comes from SecondQuantizedAlgebra.jl, which QuantumCumulants re-exports. Its documentation covers how to build a model (Hilbert spaces, operators, indices, sums), and this one covers what QuantumCumulants adds on top of it.

Quick start

Install the package with Julia's package manager:

pkg> add QuantumCumulants

A first-order mean-field model of a laser with a single atom as gain medium:

using QuantumCumulantsh = FockSpace(:cavity) ⊗ NLevelSpace(:atom, (:g, :e))@variables Δ::Real g::Real κ::Real γ::Real ν::Real@qnumbers a::Destroy(h)σ(i, j) = Transition(h, :σ, i, j)H = Δ * a' * a + g * (a' * σ(:g, :e) + a * σ(:e, :g))J = [a, σ(:g, :e), σ(:e, :g)]rates = [κ, γ, ν]eqs = meanfield([a, σ(:g, :e), σ(:e, :e)], H, J; rates = rates, order = 1)

\[ \begin{aligned} \partial_{t} \langle a \rangle &= - \langle {\sigma}^{{12}} \rangle g i + \langle a \rangle \left( - \frac{1}{2} \kappa - i \Delta \right) \\\\[-0.0em] \partial_{t} \langle {\sigma}^{{12}} \rangle &= \langle {\sigma}^{{12}} \rangle \left( - \frac{1}{2} \gamma - \frac{1}{2} \nu \right) - \langle a \rangle g i + 2 \langle a \rangle \langle {\sigma}^{{22}} \rangle g i \\\\[-0.0em] \partial_{t} \langle {\sigma}^{{22}} \rangle &= \nu + \langle {\sigma}^{{22}} \rangle \left( - \gamma - \nu \right) + \langle {\sigma}^{{12}} \rangle \langle a^{\dagger} \rangle g i - \langle a \rangle \langle {\sigma}^{{21}} \rangle g i \end{aligned} \]

The equations become a ModelingToolkit System and are integrated with OrdinaryDiffEq:

using ModelingToolkitBase, OrdinaryDiffEqLowOrderRK, Plotssys = mtkcompile(System(eqs; name = :laser))p0 = [Δ => 0, g => 1.5, κ => 1, γ => 0.25, ν => 4]u0 = ComplexF64[1.0e-2, 0, 0]prob = ODEProblem(sys, merge(initial_values(eqs, u0), Dict(p0)), (0.0, 50.0))sol = solve(prob, RK4())ts = range(0.0, 50.0; length = 200)plot(ts, abs2.(get_solution(sol, a, eqs).(ts)); xlabel = "t", label = "|⟨a⟩|²")
